# Contributing to SimpleCDC

First off, thank you for considering contributing to SimpleCDC! It's people like you that make SimpleCDC such a great tool.

## Where do I go from here?

If you've noticed a bug or have a feature request, make sure to check our [Issues](https://github.com/suryanshp1/simple-cdc/issues) if one already exists. If not, feel free to open a new one!

## Fork & create a branch

If this is something you think you can fix, then fork SimpleCDC and create a branch with a descriptive name.

A good branch name would be (where issue #325 is the ticket you're working on):

```sh
git checkout -b 325-add-new-feature
```

## Setup the environment

1. Make sure you have Docker and Docker Compose installed.
2. Run `docker compose up --build` to start the services.
3. Verify that everything is running smoothly.

## Make your changes

1. Create a new branch.
2. Make your code changes.
3. Make sure to add/update tests where relevant.
4. Update documentation if necessary.

## Submit a Pull Request

When you're ready, submit a Pull Request! We'll review your changes and provide feedback as soon as possible.
